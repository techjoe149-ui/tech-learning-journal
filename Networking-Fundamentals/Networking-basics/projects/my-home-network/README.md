# Project 1 – My Home Network

## Overview

This project documents my home network as part  of my Networking 
Fundamentals learning journey.

The objective was to inspect my local network using macOS Terminal, 
identify networking components, and document how my devices communicate 
with the Internet.


## Lessons Learned

- Learned how to identify my private IP address.
- Understood the role of the default gateway.
- Learned how DNS resolves domain names.
- Understood the difference between public and private IP addresses.
- Used ping and traceroute to verify connectivity.




## Challenges

- Initially confused the roles of a modem and a router.
- Learned that Thunderbolt Bridge is a virtual network interface on macOS.
- Needed to understand the difference between MAC and IP addresses.
