## Network Description

My MacBook connects to my home Wi-Fi network through a wireless router.

The router assigns a private IP address to my computer and forwards 
Internet traffic to my Internet Service Provider (ISP).

When I visit websites, DNS protocol translates domain names into IP addresses before my requests travel across the Internet to the destination server.
