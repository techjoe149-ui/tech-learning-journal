# Networking Fundamentals Portfolio

## Overview

This portfolio documents my practical learning and development in computer networking. It brings together networking notes, hands-on labs, troubleshooting exercises, technical investigations and projects.

The objective is to build practical networking knowledge and demonstrate the ability to understand network behaviour, investigate connectivity problems and document technical findings.

This is a developing portfolio. Its contents represent documented learning and practical work rather than professional employment experience.
